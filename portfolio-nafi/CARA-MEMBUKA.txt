PORTOFOLIO NAFI — CARA MEMBUKA

1. Ekstrak file ZIP ini terlebih dahulu.
2. Buka folder hasil ekstrak bernama portfolio-nafi.
3. Klik dua kali file index.html.
4. Website akan terbuka di browser (Google Chrome/Edge).

CARA MENGGANTI FOTO:
1. Siapkan foto diri dengan format JPG.
2. Ubah nama file foto menjadi: foto-nafi.jpg
3. Salin foto tersebut ke folder portfolio-nafi.
4. Jika Windows bertanya apakah ingin mengganti file yang sudah ada, pilih Yes/Replace.
5. Buka ulang index.html.

Catatan:
- Komputer perlu terhubung ke internet agar Tailwind CSS, Google Fonts, dan ikon dapat dimuat.
- File foto-nafi.jpg yang disertakan hanya gambar contoh. Ganti dengan foto pribadi.
- Untuk mengubah isi website, klik kanan index.html > Open with > Notepad.
